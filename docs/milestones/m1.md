# M1: Developer Confidence Preview

Status: Closed for functional scope; safety-contract corrections applied

This is the closure record for the first vertical slice in the [delivery roadmap](../roadmap.md). Its scope and rationale are fixed after closure; current implementation facts and repository gates belong in [../status.md](../status.md). New behavior belongs to a later milestone.

## Goal

Let a developer exercise a complete, isolated loop for explicitly declared local template and symbolic resources:

```text
manifest -> inspect/plan -> explicit apply -> post-apply verification
```

## Scope at closure

- one declared resource per manifest;
- local `.j2` template rendering and source symlink reconciliation;
- read-only `inspect` and `plan` commands;
- explicit `apply --yes` with stale-state checks and atomic target replacement;
- post-apply recalculation and metadata-only JSON output;
- fail-closed path and symlink safety checks.

Providers, secret persistence, baselines, reverse sync, merge resources, multi-file transactions, and a broad platform matrix are deferred. They are not implied by this milestone's completion.
